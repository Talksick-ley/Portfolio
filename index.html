About

Precision thinking. Practical building.

I am an Industrial Mechatronics student passionate about designing systems that merge the physical and digital worlds. My coursework has given me foundations in mechanical design, electronic circuits, programmable logic controllers and control systems.

Outside lectures, I explore microcontroller projects, 3D-print functional prototypes and read everything I can about autonomous robotics and smart manufacturing. I believe the next generation of engineers must be fluent in software as much as hardware.

Work

Projects.

Completed 01

Automatic Line-Following Robot

Built a differential-drive robot that follows a black line on a white surface using IR sensors and a PID control loop implemented on an Arduino Uno. Competed in a departmental challenge.

  • Arduino
  • C++
  • PID Control
  • IR Sensors
Completed 02

Temperature-Controlled Fan System

Designed a closed-loop temperature regulation system using a thermocouple, microcontroller and PWM-driven DC fan. Included an OLED display for real-time monitoring.

  • ATmega328
  • PWM
  • I²C
  • OLED
Completed 03

Conveyor Belt PLC Simulation

Programmed a simulated conveyor sorting system using Ladder Logic on a PLC trainer kit. Implemented start/stop interlocking, sensor-triggered diverters and alarm outputs.

  • PLC
  • Ladder Logic
  • HMI
  • Automation
In progress 01

6-DOF Robotic Arm

Planning a 3D-printed 6-axis robotic arm with servo actuation, inverse kinematics and a simple GUI for teleoperation. Long-term goal is computer vision pick-and-place.

  • ROS
  • Python
  • Servos
  • OpenCV
  • FDM Print
Planned 02

Smart Factory Dashboard

Concept for an IoT sensor network inside a lab environment, feeding real-time data to a web dashboard. Aims to demonstrate Industry 4.0 principles with off-the-shelf hardware.

  • ESP32
  • MQTT
  • Node-RED
  • IoT
Exploring 03

Exoskeleton Assist Joint

Researching a single-joint assistive exoskeleton prototype to explore biomechanics, servo control and human-machine interaction. Early-stage concept.

  • Biomechanics
  • Servo
  • EMG
  • SolidWorks
